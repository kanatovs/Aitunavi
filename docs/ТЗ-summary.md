# ТЗ — AITU Student Navigator (Android). Краткая выжимка и сверка с проектом

## 1. Цель
- Android-приложение для студентов: расписание (группы/преподаватели), карта кампуса (web-карта), поиск, заметки, уведомления, настройки темы/стиля.
- Без авторизации.

## 2. Платформа и ограничения
- Только Android. Языки: RU / EN. Данные из JSON. Офлайн: расписание/поиск/заметки — да; карта — web (нужен интернет). Локальные уведомления по расписанию.

## 3. Навигация (5 вкладок)
1) **Сегодня**  
2) **Chronos**  
3) **Атлас**  
4) **Поиск**  
5) **Настройки**

## 4. JSON (assets)
- `Miko.json` — расписание групп  
- `atlas_rooms.json` — аудитории/координаты/алиасы  
- `atlas_pois.json` — POI + алиасы  

Состояния: загрузка / ошибка / пусто.

## 5. Функциональные требования по вкладкам

### 5.1 Сегодня
- **Хедер:** дата (день недели, число, месяц, год), выбранная группа (тап → ввод группы), стрелки вчера/завтра, свайп по дню. Для текущего дня при наличии пар: статус NOW/SOON/UPCOMING + таймер обратного отсчёта.
- **Контент:** нет группы → «Укажи группу»; ошибка JSON → карточка ошибки; загрузка → «Загрузка…»; группа не найдена → «Группа не найдена» + сменить; нет пар на день → «Пусто» + кнопка «Полное расписание»; есть пары → список пар.
- **Быстрые действия:** кнопка «Заметка» → редактор заметки дня.

**5.1.1 Выбор группы**
- Нормализация: верхний регистр, убрать пробелы, разделители к `-`. Индикатор «Найдена/Не найдена». Кнопка «Сохранить» (только если группа есть). Список последних групп (recent) до 10.

**5.1.2 Полное расписание**
- Экран: заголовок с groupId, кнопка «Текущий день», переключатель дней (Mon…Sat), список пар. Тап по паре → Детали пары.

**5.1.3 Список пар**
- Время, статус NOW/SOON (порог 60 мин), дисциплина, комната (Online / чип / «комната +N»), преподаватель, стрелка. Тап по строке → Детали пары. Тап по чипу комнаты → Атлас (подсветить комнату) или выбор комнаты при нескольких.

**5.1.4 Детали пары**
- Дисциплина, время, блок «Комната/Преподаватель» (при нескольких локациях — список «комната → преподаватель» + «Все аудитории и преподаватели»), тип пары, карточка «Открыть на карте». Преподаватель из индекса — кликабельный (расписание преподавателя).

**5.1.5 Заметки дня**
- Привязка: groupId + date. Редактор: текст, вложения-изображения (галерея до 10, вставка из буфера, предпросмотр на весь экран, удаление), «Сохранить»/«Закрыть». Хранение: индекс в notes-index.json, изображения в папке приложения. Пустая заметка без вложений → удалить.

### 5.2 Поиск (преподаватели)
- Поле поиска, состояния: загрузка / ошибка / построение индекса. Пустой запрос → подсказки (история, затем топ по числу пар). Запрос есть → список совпадений. Строка: имя, lessonCount, тап → Расписание преподавателя. Кнопка «история», последние открытые, удалить/очистить.
- **Индекс:** из нормализованных уроков (teacherKey = нормализованная строка), отображаемое имя — самый частый вариант. Поиск по токенам, быстрый.
- **Расписание преподавателя:** шапка (имя, кол-во занятий), переключатель дня + «Текущий день», свайп по дням, список пар (время, дисциплина, группа, комната, NOW/SOON для текущего дня). Тап по паре → Детали пары, по комнате → Атлас.

### 5.3 Атлас
- Строка поиска (комната/POI), кнопка истории, панель результатов. Блок карты: выбор корпуса (3 кнопки), этаж (1/2/3), кнопка «обновить» карту, WebView. URL по умолчанию: `https://yuujiso.github.io/aitumap/`. При выборе результата/из расписания — JS: блок/этаж, подсветка комнаты (roomCode), фолбек суффиксов P/K/L. История поиска до 15, открыть/удалить/очистить.
- Поиск по atlas_rooms + atlas_pois: алиасы, скоринг (точное/префикс/содержит), разбор c1.1.234p и т.п.

### 5.4 Chronos
- Две кнопки: **Клубы** (список → карточка клуба → соцсети), **Вопросы и ответы** → «Скоро будет». Данные клубов: статический список или отдельный JSON.

### 5.5 Настройки
- Язык: RU / EN (опционально System). Тема: не менее 12 с фиксированными id. FX: 3 слайдера Master / Glow / Glass (0…1). Производительность: режим Auto/Full/Balanced/Saver, FPS Auto/Prefer 120/Cap 60. Напоминания: вкл/выкл, «предупреждать за» 5/10/15/30/45/60 мин, формат «только название»/«полная информация», звук, онлайн-пары, лекции, тип пары в полной информации, тихие часы (вкл + start/end), **«Запланировано уведомлений: N»**, кнопка в системные настройки. Инфо: Создатель (Telegram/Instagram), Партнёры (Telegram).

## 6. Уведомления
- Локальные по расписанию. Триггер = startMinutes - leadMinutes. Фильтры: includeOnline, includeLecture, includeType, quiet hours. Формат titleOnly / full. До ~60 активных. Android 13+: POST_NOTIFICATIONS. Точные по времени: AlarmManager/WorkManager. Пересоздание при смене группы, настроек, обновлении расписания, запуске приложения.

## 7. Офлайн
- Расписание, поиск (если индекс построен), заметки — работают. Карта: при отсутствии сети — «Нет интернета для карты» + «Повторить».

## 8. Хранение
- DataStore/SharedPreferences: язык, тема, FX, performance, уведомления, группа, история. Заметки: индекс (JSON/DB), вложения — файлы в приватном хранилище.

## 9. Нормализация расписания (обязательно)
- Объединение уроков в слоты по weekday + start/end + discipline(норм) + type(норм). locations[] с комнатой и преподавателем. classroom: 1 комната — показать; несколько — склеить через ` · ` или пробел при `(`/`)`. lecturer: один на все — показать; разные — пусто, показывать по локациям. online = classroom «online»/«онлайн». type lecture = «lecture»/«лекция».

# Приоритетные доработки по ТЗ

1. **Заметки:** вложения-изображения (галерея до 10, вставка из буфера, предпросмотр, удаление), хранение в папке приложения, индекс notes-index.json; удаление заметки при пустом тексте и нет вложений.
2. **Настройки:** показывать «Запланировано уведомлений: N» (реальный подсчёт).
3. **Создатель/Партнёры:** кликабельные ссылки (Telegram/Instagram).
4. **Проверить:** таймер обратного отсчёта и UPCOMING на «Сегодня», переход из деталей пары в Атлас с подсветкой комнаты, офлайн-состояние карты.

Видео (iOS) я просмотреть не могу; если нужно повторить конкретные экраны или жесты с iOS — опишите их текстом или пришлите скриншоты.
